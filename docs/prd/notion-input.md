## 一、总则

| 规则 | 说明 |
|---|---|
| Notion 优先 | Notion 输入方式与 Markdown 写法冲突时按 Notion:`>`+空格 = 折叠块,`"`+空格 = 引用,⌘/ = 「转换为」菜单(已拍板) |
| 只改输入,不改解析 | 打开别人写的 `> 内容` 仍显示为引用;打开 `~文字~`、`^文字^`、`:smile:`、`[[链接]]` 等照常显示,保存时原样写回,不改写成 Typoza 的新写法 |
| 存储优先级 | 标准 Markdown → 通用 HTML 标签 → YAML front matter;目标:用 Typora、VS Code、Obsidian 打开不丢内容 |
| 触发位置 | 块级快捷输入只在块的开头触发;行内快捷输入在闭合标记输入完成时触发;代码块、行内代码、公式、链接地址、HTML 块内一律不触发 |
| 撤回转换 | 自动转换完成后立即按 ⌘Z,撤回为输入的原字符,不再二次转换 |
| 中文输入法 | 拼音等输入法组字期间不触发;全角 `》` 等同 `>`、`“` `”` 等同 `"`、`【】` 等同 `[]`【假设】 |
| 键位总则 | Notion 键位优先于 Typora;macOS 系统保留键(⌘Q ⌘H ⌥⌘H ⌘M ⌘W ⌘, ⌘` ⌃⌘F ⌃⌘空格 ⌃⌘D ⌃⌘Q)不被占用;被挤占的 Typora 独有功能换到不冲突键位(第五节);全部键位可在偏好「快捷键」页自定义 |

## 二、Markdown 快捷输入全表

### 2.1 块级(在块开头输入)

| # | 触发串 | 结果块 | 存储语法 | 来源 | 说明 |

| 4 | `1.`+空格、`a.`+空格、`i.`+空格 | 有序列表 | `1. 内容` | Notion | 字母与罗马编号无标准 Markdown 写法,统一存数字;显示随嵌套层级为 1 → a → i【待确认:Notion 以 a./i. 起头时首层是否显示字母】 |
| 5 | `#`+空格 | 标题 1 | `# 标题` | Notion | 输入空格即转换 |
| 6 | `##`+空格 | 标题 2 | `## 标题` | Notion | 输入空格即转换 |
| 7 | `###`+空格 | 标题 3 | `### 标题` | Notion | 输入空格即转换 |
| 8 | `####`+空格 至 `######`+空格 | 标题 4 至标题 6 | `#### 标题` 至 `###### 标题` | Typora 兼容 | Notion 只到三级 |
| 9 | `>`+空格 | 折叠块 | `<details>`、`<summary>标题</summary>`、空行、内容、空行、`</details>` | Notion | 已拍板;展开收起状态不写进文件(第七节 7.6) |

| 15 | `$$` 后回车 | 公式块 | `$$` 上下包裹 | Typora 兼容 | 表格之外的空行上触发 |
| 16 | `\| 列1 \| 列2 \|` 后回车 | 表格(两列) | GFM 表格 | Typora 兼容 | 按竖线数生成列数,另加 1 行空数据行 |
| 17 | `[toc]` 后回车 | 目录 | `[TOC]` | Typora 兼容 | 目录随标题实时更新 |

## 三、粘贴网址

| 条件 | 动作 | 结果 | 存储语法 |
|---|---|---|---|
| 未选中文字,粘贴单个网址 | 先按纯链接插入,并在旁边弹出小菜单 | 【保持链接】(默认,Esc 同效)/【书签卡片】/【嵌入】 | 保持链接:原样网址;书签:`<a href="网址" data-tz-type="bookmark" title="网页描述">网页标题</a>`(单独成段,没有描述时不写 title;见 Z-08 替代实现);嵌入:`<iframe src="嵌入地址"></iframe>` |
| 网址以 .png .jpg .jpeg .gif .webp .svg 结尾 | 菜单首项换成【图片】 | 插入图片 | `![](网址)` |
| 网址以 .mp4 .mov .webm 或 .mp3 .wav .m4a .ogg 结尾 | 菜单首项换成【视频】或【音频】 | 插入媒体块 | `<video src="网址" controls></video>` / `<audio src="网址" controls></audio>` |
| 选【书签卡片】但取不到网页标题 | 卡片标题用网址本身 | 提示「无法获取网页信息,已用网址作标题」 | `<a href="网址" data-tz-type="bookmark">网址</a>` |
| 选【嵌入】但站点禁止嵌入 | 显示失败占位 | 提示「无法加载嵌入内容」与「该网站不允许嵌入,可改为书签卡片」,带【在浏览器中打开】【改为书签】按钮;离线或连不上时同样显示占位与两个按钮,没有「该网站不允许嵌入」这句 | 文件内容不变;选【改为书签】后按书签卡片存储 |

## 四、斜杠菜单与其他触发菜单

### 4.1 斜杠菜单交互

| 规则 | 说明 |
|---|---|
| 打开 | 在块开头、空格或标点后输入 `/`;或点块左侧「+」(在下方新建空块并打开菜单);单词中间、网址里(如 `http:/`、`//`)、代码块与行内代码里不触发 |
| 分组 | 基础、行内、媒体、高级、扩展五组;颜色条目单独分「文字颜色」「背景色」两组;「/turnbullet」「/turnintotoggleh1」这类直达条目只在搜索时出现 |
| 过滤 | 继续输入即过滤,忽略大小写与空格;英文命令、中文名、拼音首字母都能命中(例:`/h1`、`/标题1`、`/bt1`)【假设:拼音首字母】;排序:完全匹配 > 前缀匹配 > 包含,同档按菜单原顺序(例:`/red` 先出红色) |
| 选择 | ↑ ↓ 移动,↩ 插入;鼠标点击同效 |
| 关闭 | Esc 关闭并保留已输入的字符;无匹配时显示「无结果」,再输入 2 个字符仍无匹配自动关闭 |
| 插入位置 | 当前块为空 → 替换当前块;当前块有内容 → 插在当前块下方。动作类(复制、移动、删除、颜色、转换)作用于当前块 |

| 21 | `~文字~` | 删除线 | 下标(开启时) | — | 输入含义不同 | 输入成删除线,存 `~~文字~~`;下标从浮动工具条【更多】或格式菜单插入,存 `<sub>` |
| 22 | `$$…$$` | 行内公式 | `$$`+回车为公式块 | — | 写法相近 | 同一行内闭合 = 行内公式(存 `$…$`);`$$` 单独成行后回车 = 公式块 |
| 23 | `+`+关键字 | 链接或新建页面 | `+`+空格 为列表 | — | 与列表及正文加号冲突 | 不做 `+` 命令,由 `[[` 覆盖 |
| 24 | `#`+空格 | 立即成标题 | `#`+文字+回车成标题 | — | 触发时机不同 | 按 Notion 立即转换 |
| 25 | `:` | `:`+名称弹表情 | `:名称:`+Esc 补全 | — | 触发方式不同 | `:` 加 2 个字符自动弹出;已有 `:smile:` 照常显示 |

## 七、块级操作交互规则

### 7.1 块手柄与「+」

| 条件 | 动作 | 结果 |
|---|---|---|
| 鼠标悬停任意块 | — | 块左侧显示「+」与「⋮⋮」;文字编辑中不显示,鼠标移动后再显示 |
| 点「+」 | 在当前块下方新建空块 | 光标进入新块并打开斜杠菜单 |
| 点「⋮⋮」 | 选中该块 | 弹出块菜单(7.2) |
| 拖「⋮⋮」到其他块之间 | 移动块 | 蓝色横线指示落点;落在列表项内侧时成为其子项 |
| 按住 ⌥ 拖「⋮⋮」 | 复制块 | 原块保留,落点出现副本 |
| 拖「⋮⋮」到侧栏某个文档 | 移动块到该文档 | 块追加到目标文档末尾,当前文档移除该块;写入期间当前文档被改动过时不删原块,并提示 |
| 拖到块左右两侧 | 不出现分栏落点 | 分栏不做(无 Markdown 表示) |
| 拖动多个已选块 | 一起移动 | 保持原有先后顺序 |

### 7.2 块菜单(点「⋮⋮」,或编辑区右键菜单「块菜单…」)

| 条目 | 结果 | 说明 |
|---|---|---|
| 转换为 ▸ | 同 7.3 列表 | 搜索框可直接输入类型名 |
| 颜色 ▸ | 文字颜色 10 种、背景色 10 种(第八节) | 表格、图片、媒体、代码、公式、分割线、目录、HTML、YAML 块不显示此项;标注块显示 5 种类型(7.5) |
| 复制块链接 | 复制 `文件名#标题锚点` | 仅标题块显示;其他块无 Markdown 锚点【假设】 |
| 创建副本 ⌘D | 在下方复制该块 | Notion 同名操作 |
| 移动到… | 选择目标文档,块移到其末尾 | Notion 同名操作 |
| 复制为 Markdown | 复制该块源码 | Typoza 扩展 |
| 删除 ⌫ | 删除该块 | 可 ⌘Z 撤回 |
| 字数 | 菜单底部显示「字数 N · 字符 M」 | Notion 同名信息 |
| 上移 / 下移 | 不显示 | 移动用 ⇧⌘↑ ⇧⌘↓(块选中态)【假设】 |

### 7.3 转换为(⌘/)

| 规则 | 说明 |
|---|---|
| 目标类型 | 正文、标题 1~6、待办、无序列表、有序列表、折叠块、折叠标题 1~3、代码块、引用、标注块、公式块、新文档 |
| 批量 | 多块选中时逐块转换;混合类型时列表只显示全部可转的类型 |
| 内容保留 | 文字内容与行内样式保留;转为代码块或公式块时行内样式变为 Markdown 源码文字;代码块、公式块转正文时多行合为一个段落,行间为段内换行【假设】;折叠块与折叠标题之间互转只改级别 |
| 不可转换 | 表格、图片、视频、音频、嵌入、书签、PDF、附件、分割线、目录选中时按 ⌘/,菜单只显示创建副本、移动到、复制为 Markdown、删除 |
| 撤回 | 转换后 ⌘Z 恢复原类型 |

| 块选中态 | ⌫ / ⌘D / ⌘/ / ⇧⌘↑↓ / Tab ⇧Tab / ↩ | 删除 / 复制 / 转换菜单 / 移动 / 缩进反缩进(列表块)/ 进入编辑 |

## 八、颜色

| 规则 | 说明 |
|---|---|
| 颜色清单 | 文字颜色:默认、灰、棕、橙、黄、绿、蓝、紫、粉、红(10 种,对应 Notion default、gray、brown、orange、yellow、green、blue、purple、pink、red);背景色:同 9 种颜色的背景版 + 默认 |
| 入口 | 选中文字后浮动工具条【A】;块菜单「颜色」;斜杠 `/红色`、`/red`、`/blue background`、`/default`(斜杠菜单里分「文字颜色」「背景色」两组);⇧⌘H 应用上次颜色 |
| 存储 | 文字颜色 `<span style="color:色值">文字</span>`;背景色 `<span style="background-color:色值">文字</span>`;整块设色时包住块内全部文字,标题写成 `## <span style="color:色值">标题</span>`;列表每项各包一层 |
| 色值 | 每种颜色固定一个十六进制色值,写进文件;深色主题下显示时按主题自动调亮,文件内色值不变【待确认:色值由设计侧在设计变量中定】 |
| 默认 | 选「默认」= 去掉 `<span>` 包裹 |
| 打开已有文件 | 任意 `<span style="color:…">` 照常显示;非清单内的色值在颜色菜单中显示为「自定义」 |
| 标题锚点 | 标题加色后 `#标题` 链接仍按标题文字跳转 |
