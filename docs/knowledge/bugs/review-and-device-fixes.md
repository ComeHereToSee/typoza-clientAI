# 高风险模块审查与真机测试查出的缺陷(2026-10-23 第二期)

> 分类:bug。来源:保存与文件监视、桥接、同步、导出四块的只读代码审查,真应用冒烟新增的 7 项真机核对,以及在用户 Mac 上用电脑操作跑 CI 产物。每条都已修复;能自动化的都补了用例。

## 保存与文件监视
1. **外部修改的询问期间自动保存覆盖外部版本**:询问框开着时 1 秒的自动保存照样到点,把本地内容写盘,用户再选「重新加载」读回来的是自己的内容。`onExternalChange` 进来先停自动保存,比完、问完仍有未保存修改再排(`app/app.ts` `checkExternalChange`、`scheduleAutosave`)。
2. **写盘途中打的字被标成已保存**:写盘回执一律清掉「已修改」。`DocumentSession` 记改动计数,回执回来时计数变了就保持未保存;没改动的自动保存直接跳过(残留定时器原来会把刚打开的文档重新生成 Markdown 写回去)。
3. **同一文档两次保存乱序落盘**:外壳在后台并发写,慢的那次可能后落盘。`DocumentSession.save` 先等前一次写完。
4. **别处改过的版本在历史里留不住**:写前快照(外部版本)紧接着被写后快照按 5 分钟合并删掉。写前快照钉住(`HistoryStore.snapshotBeforeWrite`)。
5. **经符号链接打开的文件收不到外部修改**:FSEvents 报真实路径(含 /var → /private/var),网页按打开时的路径比。`FileWatcher` 按 realpath 建对照表,回调补上打开时的路径;监视的文件夹也按真实路径找。
6. **分段载入失败后能另存为覆盖成半截**:原来标成「无写权限」,⌘S 走另存为、默认同名同位置。新增只读原因 `partial`,保存拒绝、另存为不许选原文件。
7. **关窗前问网页失败按「可以关」处理**:改为弹原生确认。

## 桥接、导出、同步
8. **「复制所有图片到」网络图片必失败**:外壳 switch 里有两个 `net.download` 分支,参数名不同,只走第一个。改名并加网页与外壳的方法对照测试(`editor/tests/unit/bridge-contract.test.ts`)。
9. **自定义命令导出可被文件名、YAML 注入命令**:变量按所在位置转义(双引号里转义 `\ " $ \``,单引号里写 `'\''`,引号外整个包进单引号,`expandCommandVariables`)。
10. **Pandoc 参数错时大文档让应用闪退**:旧的 `FileHandle.write(_:)` 遇 EPIPE 抛 ObjC 异常;且写输入与读错误输出串行,可能互等。改为后台 `write(contentsOf:)`、同时读错误输出。
11. **导出不完整**:离视口远的代码块是静态占位、长代码块 CodeMirror 只画视口附近的行,导出 HTML / PDF 从界面读代码会空或截断(改为从文档取,`codeBlockText`);没画过的图表 / 公式预览导出与打印前先画齐;懒加载图去掉 `loading`;图片路径里 `% # ?` 编码、去掉「重新加载」的查询串;长文超出一张图的高度时报错而不是静默截断;离屏渲染补失败回调、网络图片最多等 10 秒。
12. **恢复码面板能直接关掉**:Esc、×、点遮罩都能关,恢复码只显示一次。面板加 `closable: false`,叠层面板 Esc 只关最上层;复制走宿主剪贴板。
13. **退出时轮换的新令牌可能没写进钥匙串**:`HelperManager.stop` 末尾等钥匙串队列写完。

## 真机(用户 Mac 上跑 CI 产物)
14. **代码块里的字在窗口不在前台时存不进文件**:`forwardUpdate` 只在 CodeMirror `hasFocus` 时同步,而 `hasFocus` 要求 `document.hasFocus()`;后台操作、系统写作工具往里写字时内容只在界面上。改为内容改动一律同步、选区只在有焦点时同步。
15. **云同步注册页露出恢复码、两步验证码**:`.tz-field { display: grid }` 盖过浏览器默认的 `[hidden]`。全局 `[hidden] { display: none !important }`(`styles/base.css`)。
16. **正文滚到顶时与窗口标题叠在一起**:标题栏透明、内容铺到窗口顶。macOS 宿主下正文上方留 28px 底色带(`:root[data-host='macos'] .tz-main::before`)。
17. **CodeMirror 按需载入后,新建代码块马上打字落到代码块外**:载入前焦点先进代码块里的隐藏输入框,建好编辑器后交给它;执行命令后 ProseMirror 会 `view.focus()` 拿回焦点,所以每次放选区都重新聚焦输入框。

## 防复发
- 外壳 switch 不报同名分支:靠方法对照测试守住。
- 「只在有焦点时做」的逻辑要分清内容与选区:内容丢不得,选区可以不跟。
- 组件给元素写 `display` 时,`hidden` 就失效;全局规则兜住。
